## 本轮新增的数学资产

不再把 G8 的 U-WBV 仅写成一句待核查假设。以可读取的最大双线性大筛引理和
Siegel–Walfisz 为经典输入，给出实际所需特例的完整推导：任意模数无关、可随 N 改变的
有界复权，支撑在 [N^(6/11),N^(2/3)]，公共截断 mp≤N，在
Q=√N/log(N)^(A+8) 内的全模数、最大约化余类平均误差为 O_A(N/log(N)^A)。
逐一处理低导子、非本原特征、π→Li 与严格端点，并保存八项对数损失账本。
显式给出对数水平不等于给出有效数值 N0；SW 的非有效性仍保留。

发现并处理一个容易漏掉的项：即使提取乘积修正 H=0，主特征仍须扣除整除 q 的素数。
实际 G8 例 N=254、m∈{25,35}、q=3 中，真实 π 主项误差为−1，而遗漏该项会得到0。
这不是原论文主定理或哥德巴赫猜想的反例，而是一个新的精确接口检查。

原始 Pan–Ding 1979 全文仍未取得；这里是从另一个明确经典输入导出的较窄命题，
不是把缺失文献标成已审查。旧 CP5 的小数主系数与全局账本没有改动。
