本页不重新编号旧结论。所有 `GB-*` ID 继续指向 v0.3 的原始语义；新工作只能：

- 增加新的、未占用 ID；

- 记录状态改变的证据；
- 不覆盖失败历史或把条件结果改写成无条件结果。
