# 目标、表述与当前状态

## 1. 二元（强）哥德巴赫

令 \(\mathbb P\) 为素数集合。精确目标是：

\[
\forall N\in 2\mathbb Z,\quad N>2
\Longrightarrow
\exists p,q\in\mathbb P,\quad N=p+q.
\]

等价地，令

\[
R_2(N)=\#\{(p,q)\in\mathbb P^2:p+q=N\},
\]

则目标为对所有偶数 \(N>2\) 证明 \(R_2(N)>0\)。

截至本基线来源边界，仓库没有记录到覆盖全部量词的独立验证证明；二元猜想保持 `open/reference_only`。任何新网络或预印本声称必须另行冻结、审计和验证。

## 2. 三元（弱）哥德巴赫

\[
\forall n>5,\quad n\ \text{为奇数}
\Longrightarrow
\exists p_1,p_2,p_3\in\mathbb P,\quad n=p_1+p_2+p_3.
\]

Helfgott 给出了无条件证明。该结果关闭的是三个素数变量的问题，不能消除二变量小弧困难，也不能推出二元猜想。

## 3. Chen 型与 \((1+a)\) 坐标

对 \(1\le a\le2\)，Li–Liu 预印本定义 Proposition \((1+a)\)：

\[
N=p+rq,\qquad r\le q^{a-1},
\]

其中 \(p,q\) 为素数，\(r=1\) 或 \(r\) 为素数。

- \(a=2\)：对应 Chen 的“素数 + 至多两个素因子的数”方向；
- \(a=1\)：本质上回到二元哥德巴赫；
- \(a=1.9\)：2026 预印本声称的无条件结果；
- \(a=1.4\)：预印本在 Elliott–Halberstam 型附加假设下声称的结果。

这些预印本结论在本仓库中保持 `preprint claim`，直到冻结证明经过独立验证。

## 4. 异常集

定义

\[
E(X)=\#\{N\le X:N>2,\ N\text{ 为偶数且 }R_2(N)=0\}.
\]

证明 \(E(X)=o(X)\) 或 \(E(X)\ll X^\theta\)（固定 \(\theta>0\)）是重要进展，但仍允许无穷多个异常数。二元猜想需要最终覆盖每一个偶数，或另有机制把残余异常逐一消灭。

## 5. 计算验证

有限验证具有形式：

\[
R_2(N)>0\qquad
(4\le N\le B,\ N\text{ 偶}).
\]

v0.3 继承的文献边界记录了验证到 \(4\times10^{18}\) 的计算结果。它是 `bounded_check`，只排除有限范围反例，不覆盖 \(N>B\)。

## 6. Evidence classes

| 标签 | 含义 | 不能推出 |
|---|---|---|
| `E` | 已建立来源结果 | 未陈述的加强或新量词 |
| `P` | 预印本作者声称 | 已同行评议或已独立验证 |
| `D` | 本项目推导 | 来源假设本身正确 |
| `H` | 启发式 | 定理真值 |
| `A` | 审计/计算结果 | 审计范围外的结论 |
| `R` | 风险或缺口 | 整条路线必然失败 |
| `T` | 可执行研究目标 | 目标已经完成 |

## 7. 不可跨越的逻辑边界

- `p+P_2` 或 \((1+1.9)\) 不是 `p+p`；
- “几乎所有”不是“所有”；
- 有限计算不是无限量词证明；
- 正的数值主项不是完整解析证明；
- 更高素数分布水平本身不自动解决筛法奇偶障碍；
- PR、CI、引用数量或模型共识都不改变数学证据等级。
