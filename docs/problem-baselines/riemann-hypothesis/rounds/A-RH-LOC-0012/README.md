## 本轮推进

前轮需要 `Q delta -> 0` 才能利用二尺度间隔。本轮允许各局部块使用不同
相位，证明带显式边界误差的局部算子传递候选定理，不再要求整体周期 Q
与缺陷 delta 满足增长关系。代价不再隐藏：必须记录没有简单点的块所占
质量 h，以及严格按次序取极限的 H。

在既定单胞周期模型、统一有界深度、简单比例趋于 2/3、delta 趋于零下，
若 `H < (101-sqrt(7321))/144 ≈ 0.10720248`，新的候选结论排除目标二尺度
预算。H 是占总质量的比例。H=0 时恢复 `5/108` 间隔；H<=10% 时仍有
精确间隔 `31/10260`。这不是现实 ζ 零点的已证覆盖性质。

本轮还说明该结果确实覆盖前轮遗漏的例子：循环应变族满足
`Q delta >= 1/96`，不能使用前轮条件，但每三个连续胞都有简单点，故可用
新的局部定理。另构造宏观无锚点区域的反例，说明不能从小缺陷自动推出
小 H；同时给出精确标量松弛点 `286/189`，定位剩余方法缺口。

## 仍未闭合

一般的周期无关二尺度命题仍未解决：本轮只在明确的 H 阈值条件下去掉
周期限制。无锚点反例本身不满足短预算，不能用来否定一般命题。
下一任务是 `A-RH-HOLE-0013`：获得更强的无锚点块能量约束，或寻找真正
同时逼近两项预算的指数配置。真实零点表示、来源权重、局部化、异常能量
和算术矩传递也仍是独立缺口。本轮没有 RH 证明或无条件零点比例改进。
