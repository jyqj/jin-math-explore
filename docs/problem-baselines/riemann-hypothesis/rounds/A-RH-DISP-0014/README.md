## 本轮接续了什么

第13轮将无简单点区域的处理转化为“局部深度方差小”的条件；本轮继续
研究能否从缺陷本身提取这项信息。回溯时找到第4轮已有的精确格点算子
不等式，故不把它重复包装成新结果。新增内容是正的深度协方差、局部
方差估计，以及任意相位下无简单点模型的精确等号分类。

## 两项主要候选进展

**深度方差由假设变为结论，但目前限于明确的格点类。** 对平方深度
`q_p=a_p^2` 建立正的非局部 Dirichlet 形式。当中心处于共同临界格点、
深度上界 `A<=log(2)` 时，得到 `D_Q(a^2)<=(64/9)delta`。
进而任意固定长度 R 的局部深度方差至多为
`(32*pi/3) R^2 sqrt(delta)`，常数不含全局周期 Q。
这允许任意多种深度，不预设深度接近共同常数。另给出显式相位扰动误差，
但没有从一般无锚点配置自动抽取小相位误差。

**无简单点区域的精确零缺陷分类。** 不预设相位齐整，允许全部占据密度：
若存在空格，零缺陷强迫全部占据点为实点、相位相同；若每格都有一对，
还允许共同非零深度。证明使用 Toeplitz 投影的边界恒等式与互反根多项式。
由此得到精确饱和无锚点模型的新短尺度下界，能排除上一轮留下的一个
标量松弛逃逸点：修正后的值为 `314/189=19/12+59/756`。
**这不是任意小缺陷序列的统一稳定性结论。**

## 同时保留了什么失败边界

两格浅深度例子说明局部方差一般只有 `sqrt(delta)` 量级，不能强行改成
线性 `delta`；缓慢深度波说明小缺陷不强迫全局深度方差小；另有精确例子
说明去掉共同格点假设后，原协方差上界会失效。这些均不是 RH 反例，也
不是满足目标长、短两套预算的均值一逃逸配置。
