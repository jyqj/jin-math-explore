## 本轮增量

接续第18轮的直接采样路线，将坐标投影的行估计推广到任意正半定测试矩阵，
并给出非恒定三角多项式权重的显式采样误差。真实来源连接仍保留全部重数和随高度
增长的深度；使用固定次临界带宽，不是假设已存在低代价单胞匹配。

推导恢复了 Montgomery–Taylor 的既有比例基准
`0.6725007036794116...`，改善的是本仓库上一轮矩形路线的常数，**不是文献新纪录**。
更重要的是，得到一个精确的局部方法边界：当带宽在 `[0.9,1]`、归一化非负
权重的上确界不超过 `1.6` 时，当前得到的全部非负对角行标量约束，都与既有
基准相容，不能仅靠继续增加这些检验推导更高比例。整个非负余弦族及其凸组合
都包含在这个范围内。该结论不限制其他带宽、峰值更高的权重、非对角相关或
更高阶信息，更不是“黎曼猜想不可推进”的断言。

最优权重处的抵消来自精确驻点方程，而非搜索没找到更好的例子。另证明偶权重
下仍可用反射对称推出中心块恒等式；非对称权重给出误差恰为 `1/9` 的反例。
源采样的实部直径余量、离散归一化和复数乘积均明确保留。
