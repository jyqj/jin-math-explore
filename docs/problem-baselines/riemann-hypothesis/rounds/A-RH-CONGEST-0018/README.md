## 实际增量

[完整证明](proof.md) 给出混合简单／非简单扇区的中心行稳定性估计，
误差为 `sqrt((4(2alpha-1)+2s)delta)/alpha^2`。这把第15轮仅适用于
无简单点扇区的短证明延伸到混合情形，不再依赖分块覆盖或深度方差。

另一项是离散矩阵到连续 sinc 算子的显式采样误差界。在固定次临界带宽
`theta<1` 下，对实际零点使用 `q=4 ceil(T log(T)/(8pi))` 维采样，
仅凭临界带和零点计数渐近，误差就是
`O_theta,alpha(T^(alpha theta-1)/log T)`。它允许归一化深度随高度增长，
不需要证明深度尾部小；也没有证明原匹配问题本身的代价小。

与第16轮基于外部配对关联定理的矩形矩结合，得到候选比例界
`0.6668685188267447...`。**这弱于所引用论文已有的 `0.672500703679...`，
不是新纪录。** 本轮价值在于完成一条不经过单胞匹配的来源连接，而非提高
已知比例。固定带宽先取高度极限，随后才让带宽趋于一；没有端点一致估计。

## 实际检验

120组主样本加6组边界配置，完成1,278个整数短维度检验和1,530个选行检验；
另对120组采样列表完成360个尺度比较、120个复变量余项检验与24次数值积分。
87,714项整数／有理检查通过。15个共振混叠检验明确保留“实跨度小于采样
周期”的必要边界。437个混合矩阵下界为正；不声称对全部测试都有效地逼近最优值。

最大积分／核残差约 `3.38e-13`。高能量配置中的未归一化选行展开残差约
`2.98e-7`，保留在[原始结果](validation.json)中，满足代码声明的尺度相关容差。
SVD秩判定和浮点断言不是形式化证明或独立验证。
