# 黎曼猜想研究档案：第13轮，无锚点区的深度一致性

Attempt: `A-RH-HOLE-0013`。工作 Issue：[#79](https://github.com/jyqj/jin-math-explore/issues/79)。
运行：`run-20260907-rh-hole-depth-13`。数学状态：**proof_candidate，未经独立验证**。

## 接续与实际增量

本轮读取并接续 [PR #77](https://github.com/jyqj/jin-math-explore/pull/77) 的第12轮
冻结证明；#78 在读取时没有独立审查 receipt。前轮用“无简单点区域的质量”
作为剩余损失，获得约10.72%的充分覆盖阈值，但不能自动证明该覆盖条件。

本轮把另一类可控制情形单独解决：**同一块内的反射对具有共同深度时，
其能量不低于保留相同中心与重数的实点模型**。这不要求共同深度为零。
不同深度的误差则由块内加权方差控制，常数不依赖全局周期。

将该比较与无须简单点作锚的实点局部能量引理组合，得到新的条件性结论：
在既定单胞模型、有界深度、简单比例趋于2/3、长缺陷趋零的前提下，若
无简单点区的局部深度方差按指定次序趋零，短尺度能量至少为
**44/27，比目标预算19/12高5/108**。不再要求洞区质量低于10.72%，
也不要求 Q delta 趋零。条件被换成了明确的深度一致性，**不是无条件消失**。

在深度上界不超过 log 2 时，还给出了保守但严格的正容差：相应极限方差
不超过10^-33即可排除两预算并存。该数很小，不宣称优化或实际可用的最优界；
其充分性由有理不等式证明，不把浮点小数当证书。

## 失败边界也已保留

任意变深度不能直接抹去。三个整数陪集上的双重点，深度取(0,2/15,0)，
在3/4尺度的能量比全实参考**至少降低3/3125**。证明含精确二阶系数和
余项界；数值复算差值约为-0.00139024346。这是有限块比较的反例，
不是满足两预算的反例，更不是黎曼猜想反例。

前轮洞区质量趋于1/3的三段族具有零块内深度方差，因此被新定理覆盖。
另一方面，前轮“小洞区、任意深度”的条件仍可能在别的情形更强；两者并存。

## 工件与复现

[proof.md](proof.md) 给出8组命题的推导、常数、两层分块及极限顺序。
[claims.json](claims.json) 给出假设、依赖、证据等级和不能推出的结论。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python check_hole_depth.py --samples 120 --output /tmp/rh-hole-validation.json
python check_hole_depth.py --check-package
```

运行版本：Python 3.13.5、NumPy 2.3.5、mpmath 1.3.0。一次6样本开发检查后，
实际执行一次120样本完整检查，加4组边界模型，共1,488次模型/尺度检查、
10,020次块检查、324组有理方差恒等式和7项有理证书检查。
16次独立积分公式计算与复数核公式最大差约1.06e-12。
这里“独立积分公式”指另一路数值计算，不是隔离的独立验证者。

数值检查不是区间证明。有限组合误差界很保守，在多数随机例上为空界；
实点零缺陷例另给出非空有限下界约1.61235。无限量词依靠候选证明，
不依靠有限采样外推。计算记录和交接含执行命令、版本、实际输出及哈希。
