# Problem baselines

本目录保存尚未进入受控 Project genesis 的问题基线。它们用于：

- 冻结精确问题、来源边界与既有结论；
- 继承历史研究资产、失败边界和可复现证书；
- 在创建 `projects/P-XXXX--.../` 前消除重复研究和状态误传；
- 为后续 source audit、candidate admission 与研究窗口提供输入。

## Authority boundary

这里的文件是 **pre-genesis reference material**，不是 Project 数学 authority：

- 合并文档不等于证明其中引用的数学命题；
- `preprint claim` 不因进入仓库而升级为已验证定理；
- 有限计算、区间证书和符号检查只覆盖其冻结输入；
- 正式 Project 仍须通过 source audit、objective freeze、受控 genesis 和独立验证。
