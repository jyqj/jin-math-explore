# 精确目标、量词与状态

来源键见 [references.bib](references.bib)，结论 ID 见 [claims.json](claims.json)。

## 1. 问题不是“素数经常靠近”

设 $\mathbb P$ 为正素数集合，$p_n$ 为第 $n$ 个素数。孪生素数猜想为

$$\forall X>0\;\exists p\in\mathbb P:\quad p>X,\quad p+2\in\mathbb P.$$

等价地，令 $\pi_2(x)=\#\{p\le x:p,p+2\in\mathbb P\}$，则目标为 $\pi_2(x)\to\infty$；也等价于 $H_1=2$。这里按较小成员 $p\le x$ 计数，而不是要求 $p+2\le x$。这是本目录统一的端点约定。[Maynard2019, Conj. 1; Stadlmann2026, §1]

等价性的简单理由：除首个相邻素数间隔外，相邻素数间隔均为正偶数；相差 2 的两个奇素数之间不能再有素数。偶整数序列的下极限为 2，意味着值 2 出现无穷多次。这是定义层推论，不是新的研究成果。

## 2. 不同命题不得混写

| 命题 | 量词及意义 | 不能推出 |
|---|---|---|
| $H_1\le B$ | 无穷多个相邻素数间隔不超过固定 $B$ | 间隔恰好 $B$；所有间隔都小；$H_1=2$ |
| 固定偶数 $d$ 无穷次出现 | $\exists d$ 可由有界间隔和有限抽屉原理得到 | 该 $d$ 就是预先指定的 2 |
| Chen 型 | 无穷多个素数 $p$ 满足 $\Omega(p+2)\le2$ | $\Omega(p+2)=1$ 无穷次 |
| 有限枚举 | 对所有 $p\le X$ 的某个有限计数 | $X$ 以外的任意无限量词 |
| Hardy–Littlewood 渐近 | $\pi_2(x)\sim2C_2x/\log^2x$ | 它不是目前已经可调用的定理 |

其中 $\Omega$ 按重数计素因子，$P_2$ 表示至多两个素因子的数，不是“必为两个不同素数的乘积”。[Maynard2019, Thm. 3; Chen1973]

## 3. 比原目标更强的数量预测

采用常数约定

$$C_2=\prod_{q>2\atop q\in\mathbb P}\left(1-\frac1{(q-1)^2}\right),\qquad
L_2(x)=2C_2\int_2^x\frac{dt}{(\log t)^2}.$$

Hardy–Littlewood 主项预测是 $\pi_2(x)\sim L_2(x)\sim2C_2x/\log^2x$。[Maynard2019, §1; Pascadi2025, Cor. 1.4]

本目录不将更强的平方根型误差猜测并入基本目标，也不把 $C_2$ 与 $2C_2$ 混用。只需证明某个趋于无穷的下界即可解决原猜想，并不一定要先证明完整渐近式。反之，上界再接近预测主项，也不能独自证明无穷性。

## 4. 两种“条件”

**数学条件：** EH 或 GEH 是分布猜想；相关结论必须保留该假设。[Maynard2015; Polymath2014b]

**形式化条件：** Lean 文件可以把一个已有但尚未形式化的数学定理作为 axiom 输入。此时文件证明的是“输入成立则结论成立”；这不自动表示论文依赖未解决数学猜想，也不表示全部输入已经通过内核验证。[PrimeGaps1862026]

186 应按第二种情况逐项审查；不能写成“假设 EH 才有 186”，也不能写成“Lean 已无条件验证所有分析与数值步骤”。
