# 方法依赖、可迁移接口与障碍

本页是路线地图，不是独立证明。[Polymath2014b; Maynard2015; Stadlmann2026; OpenAI2026]

## 1. 有界间隔的依赖图

```text
精确分布估计（指数 + 模数/权 + 剩余类 + 一致性）
           ↓ 逐个核对筛权实际产生的 lcm 模数
合法支持域 + 非负筛权
           ↓
S1 上界、S2 下界、所有带符号误差
           ↓ 严格正余量，先冻结参数，再让 x 足够大
DHL[k,2]
           + 一个已核实的 admissible k-tuple，直径 B
           ↓
H1 <= B
```

最后一条只是充分关系。找到更窄的 tuple 并不自动证明 DHL；提高优化目标也不自动证明其支持域上每一个模数都可调用分布定理。这两个接口应分别保存证书。

对 tuple $\mathcal H$，可容许性是：每个素数 $q$ 下，$\{h\bmod q:h\in\mathcal H\}$ 不覆盖全部剩余类。检查一个有限 $k$-tuple 只需检查 $q\le k$；更大的素数因剩余类数超过 $k$ 自动满足。这是有限定义检查，不是素数平移的存在性证明。[Polymath2014b, §3]

## 2. 三种分布输入不能混用

BV 给出平均于模数的平方根尺度信息。张氏 / Polymath / Stadlmann 类结果通过限制模数结构，换取超过平方根的分布能力。Pascadi 的 $5/8-\varepsilon$ 则对应特定三重良好可分解权。[Polymath2014b, §2; Pascadi2025, Thm. 1.3]

复用时必须给出调用表：`sequence / support / modulus / weight / residue / coprimality / uniformity / error / summation range`。不可仅写“已有指数大于 1/2，所以可代入”。变量换名、定向、固定剩余类与随尺度增长的剩余类都可能改变适用范围。

## 3. 奇偶障碍的准确使用

传统筛信息难以分离 $\Omega(n)$ 为奇数还是偶数。陈氏结果允许 $P_2$、有界间隔只选出 tuple 中某两个位置，正体现了不同绕行方式。[Maynard2019, §2.1; Polymath2014b, §8]

“奇偶障碍”不是给所有未来数学方法的否定性结论。Polymath8b §8 对其筛框架为何难以优于条件界 6 的讨论自称含有启发式成分；本目录不把它升级为形式化的、对所有算法普适的不可能性定理。下一条新路线应指出新增了哪类筛数据原先无法辨别的信息，而不是只宣称“优化得更充分”。

## 4. 计数上界与固定差 2 的正下界分开

上界排除“孪生素数太多”；下界才保证“它们不会停止”。假设已经知道 $\pi_2(x)\le Cx/\log^2x$，把 $C$ 降小仍与 $\pi_2(x)$ 最终恒定相容。这个逻辑边界与任何具体上界论文的正确性无关。

类似地，不能把 $p+2=P_2$ 中“至多两个素因子”直接改成“一个”。从哥德巴赫仓库迁移 switching、Buchstab 分解或误差编译工具时，也须重建问题自己的序列、符号和量词；共享工具不等于共享已验证结论。

## 5. 计算能够承担哪一层

可容许 tuple 的模运算、严格区间积分、系数有理化和形式化依赖列表都能成为可检查的有限工件。优化用浮点、证明用误差有方向的证书，二者不能合并为一句“程序通过”。完整结论还需要把有限余量接入统一渐近误差，并冻结输入和软件版本。[OpenAI2026; PrimeGaps1862026]
