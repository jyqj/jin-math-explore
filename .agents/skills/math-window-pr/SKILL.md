# Math Window PR

## Preconditions

- repository mechanical validation passes;
- the Project startup is valid;
- objective and expected old heads are bound;
- exactly three attempt reconciliation packages are complete;
- verification results bind exact candidate/dependency bytes;
- reconciliation performed no new mathematics;
- research map review closure is valid when authority/map changed;
- generated catalog is current.

## PR scope

One PR publishes one closed window. Include only Project state, immutable attempt/evidence artifacts, required map/memory/route-review updates, registry projection and regenerated catalog. Do not mix Skill/schema/protocol changes.

## Body

Use `.github/pull_request_template.md`. Report IDs, hashes, evidence grades, verification verdicts, promoted/withdrawn claims, computation handoffs, `cannot_imply`, conflicts, remaining frontier and exact checks run.

## Final review

Review the complete diff against base. A green CI result is mechanical evidence only. Request repository review and mathematical verification separately. Do not merge or push unless the user or active Goal authorizes it.
